# Code of Conduct

Laser Check follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be welcoming, be patient with people who are new to this, give and take criticism of the work rather than the person, and assume good intent. Harassment, insults and personal attacks aren't tolerated in issues, pull requests or anywhere else the project lives.

If something here makes you uncomfortable, report it privately through [GitHub's security advisory form](https://github.com/DuffleOne/laser-svg-check/security/advisories/new) or by contacting the maintainer on GitHub ([@DuffleOne](https://github.com/DuffleOne)). Reports are kept confidential.
